## ✨ Features

- **Hero & Video Intro:** Dynamic header showcasing visual media and role overview.
- **Interactive 2D Canvas Minigame:** Custom JavaScript HTML5 Canvas interactive element featuring a controllable character (Ghost) with scene transitions across multiple backgrounds (`A`/`D` or `←`/`→` keyboard navigation, plus touch support for mobile).
- **About & Background:** Summary of professional background, educational credentials from *Thakur College of Engineering & Technology* and *Sathaye College*.
- **Skillset & Expertise Matrix:** Visual showcase of competencies spanning AI/ML, Data Science, Full-Stack Web Development, Data Visualization (Power BI, Tableau), SQL, Python, and R.
- **Modern SEO & Discoverability:**
  - Semantic HTML5 markup and Open Graph / Twitter Card meta tags.
  - Comprehensive `Schema.org` JSON-LD structured data (`WebApplication`, `Person`).
  - Native XML Sitemap (`sitemap.xml`) & `robots.txt`.
  - Machine-readable AI agent context (`llms.txt`).
- **Responsive Layout:** Built with mobile-first Bootstrap 5 integration and custom vanilla CSS styling.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Sahil524/Portfolio-V.1.git
cd Portfolio-V.1
```

### 2. Run locally
You can open `index.html` directly in any modern web browser, or use a lightweight local server:

**Using Python:**
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

**Using VS Code Live Server:**
Right-click `index.html` and select **"Open with Live Server"**.
